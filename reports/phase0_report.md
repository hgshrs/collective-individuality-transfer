# Phase 0 report — reproduction and data audit

Generated by `scripts/09_phase0_report.py`. Date: 2026-09-24. All numbers below were measured in this project; paper values are quoted from Chirkov et al. (2026, *Nat Commun* 17:10133) text/figures only where verified in `refs/chirkov2026_clean.txt`.

## 1. Execution environment

- Host: Linux-6.8.0-137-generic-x86_64-with-glibc2.39, 24 CPU cores, 91 GB RAM, RTX 5080 16 GB (CUDA available: True).
- Python 3.12 via uv; torch 2.11.0+cu128, numpy 2.5.3, pandas 3.0.6, mesa 2.2.4 (paper's ABM requires the mesa 2.x API).
- R (micromamba env `rbrms`): R version 4.4.3 (2025-02-28) 2.23.0 0.9.0 2.40.0. rstan had to be rebuilt from source (conda binary was ABI-incompatible with RcppParallel).
- No sudo, no gfortran on the host; everything runs in user space.
- Paper ABM (mesa 2.2.4, single core): **0.087 s per 900-step solo run, 0.449 s per 900-step 5-agent run**.

## 2. Data audit (expected vs measured)

Full audit: `reports/data_audit.md`. Key points:

- 621 analysed participants, cell counts identical to the paper (fast A/NP/VP/FP = 73/72/86/74; slow = 71/80/79/86).
- **103 groups** (65 × 5 persons, 38 × 4 persons) — not ≈95; 4-person groups are groups with one excluded member, kept by the paper.
- 10 Hz traces (processed_traces.csv: x, z, rotation, distance, visibility, in/out-degree, social features) for all 737 recorded participants; raw traces with score and resource position for 580 sessions (download in progress, see logs/download.log).
- 1 Hz table: steps 20–880 (861 per participant); states tracking 52.2 %, searching 45.3 %, mixed 2.5 %.
- Discrepancy: discovery-event thresholds are 2 s in code vs '5 s' in the paper text; the code definition reproduces the paper's event counts exactly (829 fast / 261 slow).
- `score_first_half` is documented in the OSF README but absent from subject_data.csv.

## 3. Deviations from AGENT_SPEC defaults

- brms sampling budget reduced to 4 × (1000 warm-up + 1500 draws) with 5 threads/chain (paper: 4 × (2000 + 3000), 100 threads); convergence diagnostics reported in §4.5.
- Fig 2A/3A/3B reproduced with raw means ± 95 % CI instead of Bayesian Beta/Poisson/logistic regressions (allowed by §3.1-2).
- Angle normalisers fixed to geometric constants (45.75°, 180°) instead of sample maxima (see questions.md).
- The paper's tracking model has no participant-level random slope for distance; teacher signal = the paper's 6 random effects.

## 6. Anomalies / unresolved

- OSF download is rate-limited (HTTP 429); raw traces (needed only for score/resource position) are still downloading; not needed for Phases 0–1 (processed tables suffice).
- brms with the paper's `constant(0)` prior names worked unchanged in brms 2.23 (38 zero-fixed b terms, 4 zero sd terms, as in the paper's Rmd).
- One analysed participant has time_in_experiment = 20.0 min (an Alone participant, where validity uses resource-frame duplicates instead).

## 7. Unverified

- Supplementary tables/figures of the paper were not available (only main text PDF); paper numbers quoted are from the main text.
- Whether Unity's heading convention (atan2(x, z)) matters for any sign-sensitive feature: only absolute angles are used by the models, so it does not affect Phase 1 features.
